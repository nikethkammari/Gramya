# 🌾 Gramya – AI-Powered Organic Farming Assistant

Gramya is an AI-powered organic farming assistant built using **Python, Streamlit, and Large Language Models (LLMs)**. It is designed to help farmers get simple and practical guidance related to crops, organic farming, crop care, pests, irrigation, and sustainable agricultural practices.

The main goal of Gramya is to make AI-based agricultural assistance more accessible, practical, and easier to understand for farmers.

## 🚀 Features

- 🌱 AI-powered farming assistance using an LLM
- 💬 Natural language interaction
- 🌾 Organic and sustainable farming guidance
- 🐛 Crop and pest-related recommendations
- 💧 Irrigation and crop-care suggestions
- 📱 Interactive Streamlit web application
- 🔐 User login and guest access
- 📶 Accessibility-focused design for low-connectivity environments
- 🧠 Context-aware responses using prompt engineering

## 🧠 How It Works

The application follows a simple workflow:

**Farmer → Streamlit Application → User Query → Prompt Engineering → LLM → Agricultural Response**

The farmer enters a farming-related question through the Streamlit application. The question is processed with an agricultural context and passed to the LLM. The generated response is then displayed through the application in a simple and understandable format.
